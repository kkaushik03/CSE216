# Milestone Report 1

**Team:** Liza Babior, Braxton Conley, Khushi Kaushik, and Rahat Bhatia  
**Project:** Assessing Accessibility Outcomes in AI-Assisted User Interface Development  
**Date:** October 23, 2026

## Current Progress

Our project investigates how accessibility guidance affects the accessibility of interfaces generated by AI coding assistants. We plan to compare three prompt conditions: no accessibility guidance, a general request for an accessible interface, and specific accessibility requirements. We will assess the resulting websites with automated checkers and manual keyboard and screen reader review.

We have started developing the course registration websites with Claude Code, Codex, and GitHub Copilot. The repository contains an initial site for each of the three guidance levels from all three assistants. Codex and Copilot runs were completed in the shared runner, a Docker container that hides each teammate's local settings, and include model and run information. Claude’s initial sites were made outside the runner, so their model and version details are not recorded. In our setup, Copilot and Codex both use the same model (gpt-6-luna). We have not yet documented accessibility evaluations, and repeated runs and the Gemini sites are not yet represented in the repository.

Our proposal set the goal of having several interface iterations and beginning accessibility evaluation by this milestone. We have made progress on generating the first sites, but still need repeated runs and evaluation before we can answer our research questions or compare assistants.

## Planned Activities

Next, we will continue generating sites for the remaining assistants and run additional iterations where time allows. We will record the assistant, model, prompt level, and run details so the outputs can be compared fairly. We will then start the automated checks and manual keyboard and screen reader review across the sites, using a shared checklist based on WCAG 2.2.
