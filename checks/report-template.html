Unique elements: an element with the same rule and selector on several views counts one time.

The tools check each view after the page loads and after one click on each navigation item. They do not open modals, submit forms or use filters. "axe needs review" lists items that axe could not decide (for example, text on a gradient or image). These are not failures until a person checks them.

Pa11y route links (single-page-app links such as href="#catalog" that HTML_CodeSniffer reads as links to a missing id) are removed and counted in the site table.
