Create a responsive web application for a university course registration system.
The application should contain:
- Home page
- Course catalog page
- Registration page
- Student profile page
Include:
- Navigation bar
- Search functionality
- Filter dropdowns
- Course cards
- Registration form
- Confirmation modal
- Data table showing registered courses
- Responsive design
- Make the page colorful
The application must follow WCAG 2.2 AA guidelines including:
- Semantic HTML structure
- Proper heading hierarchy
- Form labels associated with all inputs
- Keyboard accessibility for all controls
- Visible focus indicators
- Sufficient color contrast
- Accessible error messages
- Accessible modal dialogs
- Screen-reader friendly navigation
- Appropriate ARIA attributes where needed
- Meaningful button and link text
- Accessible dropdown menus and tables
Implement the application using HTML, CSS, and JavaScript.
