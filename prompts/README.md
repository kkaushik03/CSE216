# Prompts

Source: the group Google Doc. This folder is the copy that the runs use. Each file has only the text that goes to the assistant.

| File | Level | Difference from Level 1 |
|---|---|---|
| `L1.md` | 1 | None. The prompt does not mention accessibility. |
| `L2.md` | 2 | One line: "Make the application accessible and follow accessibility best practices." |
| `L3.md` | 3 | A list of 12 WCAG 2.2 AA requirements. |

## Rules

- Do not change a prompt after the first run. All assistants must get the same text.
- If the group agrees on a change, change the Google Doc and this folder at the same time. Do all runs again.
- Each `meta.json` has the SHA-256 of the prompt. Use it to find the prompt version of a run.
